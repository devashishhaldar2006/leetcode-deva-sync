# LeetCode Solutions

A growing collection of LeetCode solutions organized into one directory per problem. The repository is maintained as an algorithm practice log for reviewing data structures, patterns, and complexity trade-offs.

## Repository layout

Each problem directory contains the corresponding solution and supporting files. Problem names and numbers are kept close to LeetCode's titles to make searching easy.

## Focus areas

- Arrays, strings, linked lists, and hash maps
- Trees, graphs, heaps, and dynamic programming
- Greedy algorithms, binary search, and sliding windows
- Clear implementations with attention to time and space complexity

Solutions are added as problems are solved; implementations may use the language best suited to the problem.
